# Backend Development Lab

Experiments 03, 05, 12A, 13 and 14. Each experiment is self-contained.

## Contents

| Experiment | Topic | Run command |
|---|---|---|
| 03 | Responsive HTML/CSS page | Open `index.html` |
| 05 | JavaScript arrays, objects and functions | Open `index.html` |
| 12A | Node.js, NPM, Express, Nodemon and EJS | `npm install && npm run dev` |
| 13 | MongoDB, Mongoose, Express registration/login | `npm install && npm run dev` |
| 14 | PostgreSQL with Express | `npm install && npm run dev` |

## GitHub upload

```bash
git clone https://github.com/YOUR-USERNAME/backend-development.git
cd backend-development
mkdir -p backend-lab
cp -r /path/to/backend-lab/* backend-lab/
git add backend-lab
git commit -m "Add backend lab experiments 03 05 12A 13 and 14"
git push origin main
```

Never commit passwords, API keys, `.env` files, `node_modules`, or database dumps. The Node projects include `.gitignore` files for this purpose.
